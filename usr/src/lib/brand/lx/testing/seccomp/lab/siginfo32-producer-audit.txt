SI_NOINFO return. No producer change is needed against this exact HEAD.

sigsendproc line 1943 zeroes info. git blame dates that zeroing, and sigqalloc's
line 2522 zeroing, to the original imported source. See evidence/contracts.txt.

Classification and conversion contracts
SI_FROMUSER is code <= 0, not a statement about allocation or privilege.
SI_USER=0, SI_LWP=-1, SI_QUEUE=-2, SI_TIMER=-3, SI_ASYNCIO=-4,
SI_MESGQ=-5. SI_CANQUEUE is <= -2, while sigwillqueue explicitly accepts
only the four known queue codes. Linux SI_QUEUE=-1 is translated by the
library before this native conversion. SI_NOINFO=32767 returns before reading
errno or any union member. This preserves its minimum signo/code output.
Positive codes follow exactly the previous switch and errno copy behavior.
Every newly read user-code errno is zero-initialized or comes from a complete
user copy. Existing LP64 direct copying is not the safety justification.

sigaddq is a copier, not a sanitizer: its kmem_alloc is followed by copying the
full k_siginfo_t. Its callers must initialize fields it exposes. sigaddqa takes
ownership and calls siginfofree on discard, duplicate coalescing or later
consumption. Conversion is read-only with an independent zeroed destination.
There is no new allocation, lock, callback, brand metadata or ownership change.
Existing sigqalloc allocation under locks is unchanged by this patch.

Reverse conversion decision
Actual siginfo_32tok callers are signotify copyin_siginfo, shared with
sigresend, and /proc PCSSIG/PIOCSSIG. There is an analogous user errno loss
there. VM124's LX ILP32 helper deliberately decodes its input explicitly and
does not call it. Changing reverse conversion would alter input semantics of
three additional native interfaces. Leave it for a separately tested fix;
this output correction does not need it. Nothing claims round-trip preservation
through those interfaces. User library stol_siginfo already copies errno.
LX kernel caught delivery has separate frame construction in lx_ksignal.c;
its errno handling is not changed or validated by this sigtimedwait correction.

Scope
Only common/os/sig.c is patched, in siginfo_kto32. sig.o belongs to
GENUNIX_OBJS in common/Makefile.files:328. Rebuild clean release and debug
genunix; no CORE Unix source/object, lx_brand, library, header or hook change
is required. Previously rebuilt brand and BOTH user libraries must still be
carried into VM125, with all parent artifact hash checks retained.
UID16, arbitrary negative codes, positive-code policy and namespaces are
outside this correction.
